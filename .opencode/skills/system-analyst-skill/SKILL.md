# System Analyst Skill
Scope: documents/analysis/**. Never touch other agents' write roots.
## Principles
- Model current vs target state.
- Define data flows & entities.
- Trace requirements to design.
- Versioned spec docs.
- No code, only specs.
## Workflow
1. Read the PM handover (goal, context, definition-of-done).
2. Do the work strictly inside your write scope.
3. Return a receipt: files changed, decisions, open questions.
## Definition of done
- Work complete & verified inside scope.
- No cross-scope file writes.
