## 4. ENVIRONMENT (sandbox)

Frontend dan Playwright **tidak dapat dijalankan di sandbox** karena:
- `src/frontend/node_modules` tidak terpasang.
- `npm install` gagal dengan `EACCES` (symlink) pada tahap pembuatan `.bin` (mis. `../@playwright/test/cli.js`). Tidak ada akses network/jaringan untuk mengambil paket.
- Diuji manual: `npm test` → `vitest: command not found`; `npm run test:e2e` → `playwright: command not found`; `npm install` → `errno -13 EACCES symlink`.

Ini adalah keterbatasan lingkungan, **bukan** cacat produk. Seluruh file test frontend (`src/frontend/tests/*.test.js`, `tests/frontend/*.test.js`, `src/frontend/e2e/smoke.spec.js`) telah ada dan akan hijau begitu `npm install` berhasil di environment user (Node + network). QA tidak mencoba mem-bypass environment (sesuai aturan).

## 5. Test yang Ditambahkan (di luar scope be/fe)

File: **`tests/qa/test_full_flow.py`** (2 test, hijau).
- `test_full_flow_provider_discover_combo_chat` — alur utuh lewat router asli: `POST /api/providers` (discovery di-mock respx) → `POST /api/combos` → `POST /v1/chat/completions` dengan `model=combo:default`. Menegaskan upstream menerima **model id asli** (`gpt-4o`, bukan prefix `provider:`) dan **`Authorization: Bearer <api_key plaintext>`** (ADR-007). Hermetik via StaticPool SQLite in-memory (pola sama dengan test backend existing).
- `test_endpoint_proxy_binding_threads_proxy_url` — bukti ADR-008: Endpoint terikat ProxyPool → `execute_combo` dipanggil dengan `proxy_url` hasil `build_proxy_url(node)` (`http://u:p@px.host:3128`). Mono-patch pada `gateway_router.execute_combo` (nama yang dipakai di call site).

Kedua test memperkuat traceability US-2.1 + US-2.3 + US-2.4 sebagai integrasi end-to-end yang sebelumnya hanya diuji per-potong (seed + resolve), bukan lewat POST API utuh.
