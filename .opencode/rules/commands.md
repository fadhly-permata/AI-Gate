# COMMANDS
One need, one command file. Multi-action via param system, not many file.
Example: `/skill get|search|delete|help`.
Add help alias: `help` / `info` / `information` / `?`. List supported param + aim.
Low friction: auto-detectable param never asked. Auto fields (id, date, severity, path) never typed.
Auto-probe context (current branch, task id, target file) before prompting user.
