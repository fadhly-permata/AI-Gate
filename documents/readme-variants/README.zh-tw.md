# aigate 🚪

你常用的 AI 供應商，全部走同一個入口；AI agent 會替你寫程式；
甚至連手機都能跑。

它就是一個普通的 Python 應用程式：不用 Docker、不用雲端帳號，
金鑰和紀錄都留在你自己的裝置上。

## 下班，搭捷運回家 ☕

尖峰時段的車廂有點擠，你抓著吊環，用手機開瀏覽器——
下午那個專案的報錯還掛在那裡。打一句話給 agent，按下執行，
終端機的分頁就活了起來：跑測試、讀錯誤、修一個、再跑一次。
你就這樣看著它一站一站地修。最後一個錯誤消失，修正合併回
主分支，臨時的分支無聲地退場。整件事，發生在你手機的一個
瀏覽器分頁裡。

## 有什麼不一樣 ✨

- **所有供應商，同一個入口。** 各家帳號先連一次，
  之後的請求都由 aigate 自動分派。某一家掛了、或額度用完了，
  請求還是會被其他家接走，不會白白失敗。
- **24 個 AI 程式輔助工具，開一個分頁就能跑。** aigate 直接在
  內建的終端機分頁裡執行它們。某個工具沒裝？它會給出一條在
  這台裝置上真的能用的安裝指令。這份清單還在持續擴充，
  後續版本可能增加或調整工具。
- **看得見的自動修復迴圈。** 它會自己開一個分支，在看得見的
  分頁裡跑 agent，一條一條把錯誤修好，測試通過後再合併回去；
  沒修好絕對不會假裝成功。
- **手機上真的跑得起來。** 在 Android 的 Termux 裡就能安裝、
  直接啟動，不需要編譯器，也不需要建置工具。
- **金鑰和紀錄留在本機。** API 金鑰與使用紀錄都只是裝置上的
  本機資料；除了你自己選的那幾家 AI 供應商，不會有任何東西連到雲端。
- **用起來舒服。** 有亮、暗兩種主題，內建 7 種語言，
  小螢幕也排得整整齊齊。

## 60 秒跑起來 ⏱️

```bash
python run.py
```

瀏覽器打開 **http://localhost:8080** 就看到了。第一次啟動時，
它會自動抓好需要的幾個 Python 套件，然後開始跑。

連接埠被佔用？換一個：

```bash
AIGATE_PORT=9090 python run.py
```

## 在手機上跑 📱

Android 裝一支 Termux，把 aigate 這套軟體放進去，啟動方式和
電腦上一模一樣，再用瀏覽器打開就好。手機上比較麻煩的其實是
那些程式輔助工具本身——Android 裝套件的方式和電腦不同。aigate
認得出自己跑在 Termux 上，給你的安裝指令會是那台裝置真的能用
的版本，例如改裝系統套件，而不是電腦上的那一條。

aigate 已在 Linux、Windows、Android (Termux) 上測試過，
包括在手機裡跑一個完整的 Linux 發行版。
