# aigate 🚪

Один вход для всех AI-провайдеров, с которыми вы работаете. Агент, который
сам пишет код. И всё это помещается в кармане — запускать можно с телефона.

Само по себе это обычное Python-приложение: без Docker, без облачного
аккаунта.
API-ключи и история запросов остаются на устройстве.

aigate бесплатен, а его исходный код открыт — платных тарифов нет, и ничего
не скрыто за подпиской. Скопировать этот код может кто угодно, поэтому
единственный официальный адрес aigate — [github.com/fadhly-permata/AI-Gate](https://github.com/fadhly-permata/AI-Gate).

## Вечерняя электричка ☕

Едете домой, силы на нуле. С утра в проекте падают тесты, а включать
редактор не хочется. Открываете в телефоне браузер и пишете агенту одну
короткую фразу. Он начинает работать во вкладке терминала, и вы эту вкладку
видите: запуск тестов, чтение ошибки, правка, снова запуск. Вы смотрите в
окно и считаете станции. Когда ошибки заканчиваются, агент делает merge в
основную ветку, а временная ветка исчезает. Выходите на своей станции —
проект уже чистый.

## Что делает его другим ✨

- **Все провайдеры — через одну дверь.** Аккаунты подключаете один раз.
  Дальше aigate сам решает, через кого отправить запрос. Провайдер лежит
  или квота кончилась — aigate переключает запрос на другого, и ответ всё
  равно приходит.
- **24 AI-инструмента для кодинга — в один тап.** aigate запускает их
  прямо во встроенных вкладках терминала. Инструмента нет на машине?
  aigate покажет команду установки, которая подойдёт именно этому
  устройству. Список ещё развивается — в следующих версиях он может
  измениться.
- **Самопочинка у вас на глазах.** Указываете aigate проект, в котором
  сыпятся ошибки: он создаёт ветку, запускает агента во вкладке, которую
  вы видите, чинит ошибки по одной и в конце делает merge обратно. Ничего
  не спрятано — и он никогда не делает вид, что всё получилось, если на
  деле упало.
- **На телефоне это работает по-настоящему.** На Android aigate ставится и
  запускается прямо в Termux: никаких компиляторов и инструментов сборки, и
  ничего такого, что работает только на десктопе.
- **Приватность по умолчанию.** API-ключи и история запросов — обычные
  локальные файлы на вашем устройстве. Наружу уходят только запросы к тем
  провайдерам, которых выбрали вы.
- **И просто приятно в руках.** Светлая и тёмная тема, семь языков
  интерфейса, и на маленьком экране тоже удобно.

## Попробуйте за 60 секунд ⏱️

```bash
python run.py
```

Заходите на **http://localhost:8080**. Первый запуск сам тянет нужные
Python-пакеты — их немного — и поднимает интерфейс.

Порт занят? Возьмите другой:

```bash
AIGATE_PORT=9090 python run.py
```

## На телефоне 📱

На Android всё живёт в Termux. Ставите туда aigate и запускаете так же, как
на ноутбуке, — интерфейс открывается в браузере. Сложность на телефоне не в
aigate, а в самих инструментах для кодинга: Android ставит пакеты по другим
правилам, чем десктоп. aigate понимает, что сидит в Termux, и предлагает ту
команду установки, которая там действительно сработает, — например
системный пакет вместо десктопного.

Проверено на Linux, Windows и Android (Termux), включая запуск
полноценного Linux-дистрибутива внутри телефона.
