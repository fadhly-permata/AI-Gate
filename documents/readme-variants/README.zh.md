# aigate 🚪

所有 AI 提供商走同一个入口。

AI agent 替你写代码，你负责看。

手机上也能跑。

就是一个普通的 Python 应用：不用 Docker，不用云账号，
密钥和记录都留在你自己的设备上。

## 下班路上 ☕

地铁到站前半小时，你突然想起下午那个 bug 还没修完。

掏出手机，打开 aigate，给 agent 丢一句话：把测试里报的错清一清。

终端标签亮起来——跑测试、看报错、改代码、再跑一遍。

你靠着扶手刷完这一轮，报错清零，改动自动合回主分支，
临时分支安静消失。全程没碰电脑。

## 有什么不一样 ✨

- **所有 AI 提供商走同一个入口。** 账号接好一次，请求自动分发。
  某家挂了或者额度用完，请求转给下一家，不会直接失败。
- **24 个 AI 编程工具，点开就用。** 直接在内置终端标签里跑。
  工具没装？aigate 会给出在这台设备上真正能用的安装命令。
  **这份清单还在持续扩充**——后续版本可能会增加或调整工具。
- **自动修复循环，全程看得见。** 指向项目里的报错，它自己开分支，
  在看得见的标签页里跑 agent，一条一条把报错修掉，通过后再合并回去。
  **没修好绝不会假装成功。**
- **手机上原生运行。** 在 Android 的 Termux 里装好就能跑，
  不需要编译器，也不需要构建工具。
- **数据留在本地。** 密钥和记录都是设备上的本地数据。
  除了你选的提供商，没有任何请求发去云端。
- **用着舒服。** 明暗主题，应用内置 7 种语言，小屏幕也好用。

## 60 秒跑起来 ⏱️

```bash
python run.py
```

打开 **http://localhost:8080**。第一次启动会自动装好几个
Python 依赖包，装完就起。

端口被占用？换一个：

```bash
AIGATE_PORT=9090 python run.py
```

## 在手机上跑 📱

Android 上装个 Termux，把 aigate 放进去，
启动方式和电脑上一模一样。

麻烦的其实是编程工具本身：安卓装包的套路和桌面不一样。
aigate 认得出自己在 Termux 里，给出的安装命令在这台设备上就能跑通。

已在 Linux、Windows、Android (Termux) 上测试过，
包括在手机里跑一个完整的 Linux 发行版。
