# aigate 🚪

使っている AI プロバイダは、一つの窓口にまとまります。AI エージェントが
コードまで書いてくれます。しかもスマホからでも動きます。

Docker は要りません。クラウドのアカウントも要りません。aigate はごく普通の
Python アプリです。APIキーも履歴も、手元の端末にだけ残ります。

aigate は無料で、ソースコードも公開されています。有料プランはなく、課金しないと
使えない機能もありません。誰でもこのコードを自由にコピーできるため、aigate の公式な配布先は
ひとつだけです: [github.com/fadhly-permata/AI-Gate](https://github.com/fadhly-permata/AI-Gate)

## 満員電車の帰り道 ☕

吊革につかまって、スマホのブラウザを開きます。午前から放置したサイド
プロジェクトが、まだエラーを吐いているんです。一行だけ入力して、実行。
タブが動き出して、エラーをひとつずつ片付けていきます。テストを回し、
原因を読み、直して、また確認。窓の外はもうすぐ最寄り駅です。最後の
エラーが消えると、修正はメインのブランチへ。作業用のブランチは、
音もなく消えます。閉じるのは、ブラウザのタブひとつ。

## ここが違う ✨

- **すべての AI プロバイダを、一つの窓口で。** プロバイダのアカウントを
  つないでおけば、リクエストは aigate が振り分けます。ひとつが落ちていても、
  クォータを使い切っていても、別のプロバイダが応えます。
- **24 種類の AI コーディングツール。** 内蔵ターミナルのタブでそのまま
  起動します。未インストールなら、その端末で実際に動くインストール
  コマンドを表示します。このリストはこれからも増えます。次のバージョンで
  変わるかもしれません。
- **中身が見える自動修復ループ。** エラーだらけのプロジェクトをぶつけると、
  ブランチを作り、見えるタブでエージェントを動かし、エラーをひとつずつ
  直して、テストが通ったらマージして戻ります。失敗しているのに「できた」と
  嘘をつくことは、絶対にありません。
- **スマホで本当に動く。** Android では Termux にそのまま入ります。コンパイラも
  ビルドツールも要りません。デスクトップ前提の仕組みは使っていません。
- **既定でプライベート。** APIキーと履歴は端末の中のローカルデータです。
  通信するのは、自分で選んだ AI プロバイダだけ。クラウドに勝手に送ることは
  ありません。
- **使いやすい画面。** 明暗テーマ、7 言語。小さい画面でも扱いやすい
  つくりです。

## 60秒で試す ⏱️

```bash
python run.py
```

**http://localhost:8080** をブラウザで開いてください。初回は必要な Python
パッケージを自動で入れてから、起動します。

ポートが埋まっていたら、番号を変えます:

```bash
AIGATE_PORT=9090 python run.py
```

## スマホで動く 📱

Android なら Termux にインストールして、ノート PC と同じように起動します。
ブラウザで開けば準備は終わりです。スマホで手間取るのは、コーディングツール
自身のインストールです。Android はパッケージの入り方がデスクトップと
違うからです。aigate は Termux を見分けて、その端末で本当に動くコマンドを
提案します。デスクトップ用のものをそのまま出したりはしません。

動作は Linux / Windows / Android (Termux) で確認済みです。スマホの中で
完全な Linux ディストリを動かす構成でも、動作を確認しています。
